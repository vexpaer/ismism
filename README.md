# 主义主义 · ISMISM

一个以“秩序、冲突、中心、虚无”为递归坐标的三维思想索引。

主页不是可以被打乱的益智魔方，而是坐标锁定的“主义坐标体”：

- 外层五面分别进入形而下学、形而上学、观念论、实践与现代性。
- 进入领域后，每层固定为四个位置：秩序、冲突、中心、虚无。
- 点击方块会放大当前选择、淡出同层节点，并展开下一层。
- 每个坐标都可以进入 Wiki 风格的思想词条。
- Canvas 之外保留完整的 DOM 导航、搜索和减少动态效果支持。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

## 技术结构

- Vite：静态构建与 GitHub Pages 子路径支持
- Three.js：立方体、射线选择与受限旋转
- GSAP：入场、下钻、淡出和 Wiki 转场时间线
- Hash 路由：保证 GitHub Pages 深层刷新不返回 404

## 内容说明

当前版本已从原始坐标表中分区提取并人工复核 365 个已命名坐标；加上五个总域，共提供 370 个可搜索、可分享的 Wiki 页面。“形而下学 → 科学实在论 → 物理主义 → 有机进化论”等重点路径已有扩展正文，其余基础词条已完成标题、坐标、路径和四象位置说明，后续可继续补充思想史资料。

构建完成后，脚本还会为每个词条生成真实的静态入口，例如：

```text
/ismism/wiki/1-1-1-2/
```

空缺位置仍保留为“尚未收录”，不会为了填满界面而虚构词条。

思想坐标是一种可讨论的编辑结构，不被呈现为唯一、绝对或价值中立的哲学分类。
